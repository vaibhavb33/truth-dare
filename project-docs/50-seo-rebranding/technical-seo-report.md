## 2. Robots.txt Specification & Validation

The application serves a dynamic `robots.txt` generated by Next.js via `app/robots.ts` at `https://playtruthndare.com/robots.txt`:

```txt
User-agent: *
Allow: /
Disallow: /admin
Disallow: /admin/
Disallow: /api/
Disallow: /room/

User-agent: Googlebot
Allow: /
Disallow: /admin
Disallow: /admin/
Disallow: /api/
Disallow: /room/

User-agent: Bingbot
Allow: /
Disallow: /admin
Disallow: /admin/
Disallow: /api/
Disallow: /room/

Sitemap: https://playtruthndare.com/sitemap.xml
```

### Key Technical Safeguards:
1. **Explicit Search Engine Directives:** Specific entries for `Googlebot` and `Bingbot` guarantee crawl budget prioritization on high-value public pages.
2. **Ephemeral Room Shielding:** Multiplayer lobbies (`/room/[code]`) contain rapidly changing state and session IDs. Disallowing `/room/` prevents crawler entrapment, infinite URL parameter loops, and thin/duplicate content penalties.
3. **API & Admin Shielding:** Disallows crawler hits to `/api/` endpoints, preserving backend CPU and WebSocket concurrency.

## 3. Canonical URL & Hreflang Implementation

### A. Canonical Rules
1. **Primary Origin:** `https://playtruthndare.com` (Naked HTTPS domain).
2. **English Canonical URLs:** English is the default locale and is rendered at un-prefixed root paths (e.g. `https://playtruthndare.com/games/truth-or-dare`), preventing `/en` duplicate content loops.
3. **Localized Canonical URLs:** Localized pages have explicit self-referencing canonicals with language prefixes:
   - Spanish: `https://playtruthndare.com/es/games/truth-or-dare`
   - Hindi: `https://playtruthndare.com/hi/games/truth-or-dare`
   - French: `https://playtruthndare.com/fr/games/truth-or-dare`
   - Indonesian: `https://playtruthndare.com/id/games/truth-or-dare`
   - German: `https://playtruthndare.com/de/games/truth-or-dare`
   - Portuguese: `https://playtruthndare.com/pt/games/truth-or-dare`
   - Arabic: `https://playtruthndare.com/ar/games/truth-or-dare`

### B. Reciprocal Hreflang Alternates
Generated via `getLocalizedAlternates(subpath, currentLocale)` in `lib/i18n/seo.ts`:
```html
<link rel="canonical" href="https://playtruthndare.com/games/truth-or-dare" />
<link rel="alternate" hreflang="en" href="https://playtruthndare.com/en/games/truth-or-dare" />
<link rel="alternate" hreflang="hi" href="https://playtruthndare.com/hi/games/truth-or-dare" />
<link rel="alternate" hreflang="es" href="https://playtruthndare.com/es/games/truth-or-dare" />
<link rel="alternate" hreflang="pt" href="https://playtruthndare.com/pt/games/truth-or-dare" />
<link rel="alternate" hreflang="fr" href="https://playtruthndare.com/fr/games/truth-or-dare" />
<link rel="alternate" hreflang="id" href="https://playtruthndare.com/id/games/truth-or-dare" />
<link rel="alternate" hreflang="ar" href="https://playtruthndare.com/ar/games/truth-or-dare" />
<link rel="alternate" hreflang="de" href="https://playtruthndare.com/de/games/truth-or-dare" />
<link rel="alternate" hreflang="x-default" href="https://playtruthndare.com/games/truth-or-dare" />
```
- **Bidirectional Reciprocity:** Each language version declares reciprocal alternates pointing to all other 7 locales plus `x-default`.
- **x-default Strategy:** Resolves to the default English canonical URL for all international users whose browser language does not match the 8 explicitly supported locales.

## 6. Core Web Vitals & Frontend Performance Optimization

### A. Layout Stability (CLS < 0.05)
- All card flip containers, wheel canvases, and hero headings have fixed aspect ratios or reserved min-heights.
- Custom fonts (`Outfit` and `Plus Jakarta Sans`) load with `display: swap` and metric fallbacks through `next/font/google`, preventing FOIT/FOUT layout shifts.

### B. Fast First Contentful Paint (FCP < 1.0s) & LCP (< 1.8s)
- **Zero Raster Hero Overhead:** The primary brand visual is lightweight inline SVG vector artwork (`BrandLogo.tsx`, `BrandIcon.tsx`), eliminating 500KB+ hero image downloads.
- **Zero External Banner Ads:** The platform features zero third-party ad networks, tracking pixels, or synchronous external SDKs, preserving maximum CPU capacity for game state and 3D animations.
- **Synthesized Audio:** Audio effects (chimes, clicks, timers) use the browser's native Web Audio API (`SoundSynthesizer.ts`), generating dynamic synthesized sounds programmatically with 0 bytes transferred over the network.

### C. Mobile Responsiveness
- Viewport configured: `width=device-width, initial-scale=1, maximum-scale=5`.
- Tested and verified across all standard responsive breakpoints:
  - **320px** (iPhone SE 1st gen)
  - **360px** (Galaxy S8)
  - **375px** (iPhone 13 mini / SE)
  - **390px** (iPhone 14 / 15)
  - **414px** (iPhone XR / 11)
  - **430px** (iPhone 15 Pro Max)
  - **768px** (iPad mini)
  - **1024px** (iPad Pro)
  - **1440px** (Desktop widescreen)
- Mobile bottom dock (`MobileDock.tsx`) provides thumb-accessible navigation on small screens while automatically hiding during active card flip gameplay or multiplayer room sessions.
